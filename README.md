# Short-let apartment website

## 1. Edit your details
Open `script.js` and change the `CONFIG` block at the top: name, location, WhatsApp number (format: 2348031234567), price per night, guests, amenities, description.

## 2. Add your photos
Put your photos in the `images` folder named `1.jpg` to `6.jpg` (1.jpg is the main photo). Keep each under about 400 KB for fast loading on mobile.

## 3. Host it free (about 2 minutes)
- Netlify: go to app.netlify.com/drop and drag this whole folder onto the page.
- Or GitHub Pages / Cloudflare Pages: upload the folder and enable Pages.
Then connect a custom domain (e.g. yourapartment.com) in the host's domain settings.

## How booking works
Guests choose dates and guest count, see an estimated total, then tap "Send request on WhatsApp". WhatsApp opens with the details filled in for the owner. No backend or payment is required.
